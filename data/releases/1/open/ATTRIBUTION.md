# Attribution, open data release 1 (2026-11-15)

This dataset is published by EV Shortlist under CC BY 4.0 (see LICENSE). It is built from the sources below; each keeps its own licence and credit. Only sources that passed our licence gate are included. Data under ODbL (e.g. OpenStreetMap) is never included. Values from `seed-manual` are hand-entered and unchecked.
