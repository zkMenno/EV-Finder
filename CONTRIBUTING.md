# Contributing

Thanks for wanting to help. EV Finder is built by one maintainer working with AI coding agents, so the process is light but strict about scope.

## The most useful help

- **Data corrections.** Use the [data issue form](../../issues/new?template=data-issue.yml). Always include a source.
- **Bugs.** Use the bug form.
- **Ideas.** Use the idea form. Scope is kept tight on purpose (see ROADMAP.md).

## Code contributions

1. Open an issue first, so we can agree it fits before you spend time on it.
2. Read [AGENTS.md](AGENTS.md). It holds the conventions for humans and agents alike.
3. One change per pull request, with tests, and green CI.

## Licensing of contributions

Code is licensed under AGPL-3.0 and published data under CC BY 4.0. By opening a pull request, you agree that:

- your contribution is your own work (or you have the right to submit it), and
- it's licensed under the project's licence, **and** the maintainer may relicense it under other terms in the future (for example, a more permissive open-source licence or a commercial licence for the API).

This keeps the project able to change licence later without having to track down every contributor. If you don't want to agree to this, please say so in the pull request before it's merged.
