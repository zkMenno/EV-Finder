## Product
- 2026-11-14 — One-liner: EV Database, but built for finding used EVs, across more markets, with the features it's missing. Lean; strict scope guard (Core = phases 0–2, Next = 3–5, Later = parked).
- 2026-11-14 — Finder only (link out); no hosted listings, messaging, payments, leasing deals or own forum.
- 2026-11-14 — Landing page = Explore table: new and used prices side by side; table/cards toggle (remembered); compare tray that never resets; no signup needed.
- 2026-11-15 — Simple by default, nerdy on demand: plain-language labels with the technical term underneath; ⓘ tooltip on every term (one or two sentences, no jargon) reading from a glossary_terms table (6 languages, Sveltia-editable); detail switch Simple / Detailed / Nerd (remembered, in the URL); Nerd shows raw values, curves, every source with date and confidence, conflicts, fallback rung and downloads. Five-person normie test before launch (plan: repo research/R-30).
- 2026-11-14 — Vehicle scope: BEV cars only at launch; PHEVs with 80 km+ electric range = likely Next (own column, kept out of BEV rankings); vans Later.
- 2026-11-14 — Catalogue: everything, like EV Database (~1,500 models/variants), with quality tiers (checked / sourced / single source). Top 40 used models hand-checked first.
- 2026-11-14 — Languages at launch: EN, NL, DE, FR, ES, IT.
- 2026-11-14 — Used prices: pre-filled "See listings" searches per country marketplace. Ranges from layer 0 (free published price indices: Autotrader UK RPI, AutoScout24 AGPI, Indicata, Recurrent), layer 1 (partner/affiliate feeds), layer 3 (low-rate automated sampling, aggregates only, kill switch per site, legal check first); layer 2 (manual sample) as backup.
- 2026-11-15 — Ways to pay (repo Decision 017, Menno's idea): every price switches between buy outright, loan per month (our calculator, typical rates per country, CCD2 warning) and lease per month (partner feeds only; labelled link otherwise). No finance commission at launch; no UK finance/lease links until the FCA question is checked.
- 2026-11-15 — Partnerships first: ~8 groups own most marketplaces (Autonex/AutoScout24, Adevinta, OLX Group, Vend, CAR Group, Carsome, Mercado Libre + independents). Pitch Autonex, Adevinta, Vend, OLX Group in Phase 1.
- 2026-11-14 — Accounts light: anonymous-first, passkey/magic link, favourites, shortlists, saved + shared comparisons, dashboard, GDPR export/delete.
- 2026-11-14 — Community: owner data + reviews later; first just link into existing communities and offer "report a data issue".
- 2026-11-14 — Real-world range and charge speed computed ourselves; EV Database only as manual cross-check.
- 2026-11-14 — Real-range sources: Bjørn Nyland (ask permission, credit, sponsorship once revenue exists) plus NAF/Motor El Prix, ADAC, Edmunds, InsideEVs/Out of Spec, Consumer Reports, Spritmonitor. Tests stored with conditions.
- 2026-11-15 — DC charging shown as real numbers, never peak kW alone: average kW and minutes 10–80%, km added in 10/20 min, "peak held for N minutes", claim vs measured, winter time. DC ranking uses km in 20 min.
- 2026-11-15 — New filters EV Database lacks: voltage class (400 V / 800 V / 900 V+ from an editable table, plus a nominal-voltage slider), "fast on older 400 V chargers", chemistry (with pros/cons/care popovers and "new" badge for emerging chemistries), battery cooling (air-cooled packs flagged on used cars), "charge to 100% daily". /learn page per chemistry and voltage class.
- 2026-11-15 — Charging buildout (spec tab "Charging buildout"; repo Decision 012): per-country charging pages from official statistics (points over time, AC vs DC, DC by power band, EVs per point, history to show it's not 2019 any more); a /learn page "Charging in 2026" for first-time buyers (tap-to-pay at fast chargers under EU AFIR and UK rules, no subscriptions needed, plugs, prices, motorway coverage); a link-out block to existing tools (ABRP, PlugShare, Chargemap, Electromaps, Chargeprice, Open Charge Map, Zapmap, official maps); ABRP deep link with the car pre-selected on model pages. No charger map of our own (Later/parked). Link-outs + learn page = Core phase 1; country pages + ABRP car deep link = Core phase 2; EAFO Europe comparison and "how this car fits the network" = Next.
- 2026-11-15 — Bidirectional charging + plugs (spec tab "Bidirectional & plugs"; repo docs/spec/bidirectional-and-connectors.md, research/R-01 (corrected by R-25), repo Decision 011, tasks T-018–T-022): filters "can power your home (V2H)", "can feed the grid (V2G)", "no expensive special box (AC route)", "ready for the 2027 standard (ISO 15118-20)", defaulting to live in the selected country; caveat badges from a taxonomy (needs DC box ≈€2–3k, maker box/tariff only, min software/battery/build date, discharge cap, CHAdeMO legacy); used-car checklist on model pages. Copy rule: from 1 Jan 2027 new/renovated EU wallboxes (home too) must speak ISO 15118-20, which is the protocol, not bidirectional hardware. US: CCS1 vs native NACS per model year + "plugs into Superchargers" filter (Next, phase 4). Schema + EU ports + "wallbox from 2027" learn section = Core 1; bidi filters = Core 2.
- 2026-11-15 — Trip fit (spec tab "Trip fit"; repo Decision 013): optional flow "Find cars for my trips" = usage profile picker (only/main/second car, long trips, where you charge, driving mix, extras) + places with frequency (weekly / monthly / few times a year / must reach without charging) and destination charging + winter settings (climate-normal January default, cold-snap toggle, preheat, driving style, buffer). Output: "range you truly need" (winter km on your mix + WLTP-equivalent), Explore column ✓/⚠/✗ + Fit score, hard filter for must-do trips, model-page widget, used-battery health applied. Model = per-road-band consumption × temperature curve per heater type + warm-up per cold start + climb, fallback ladder (measured → platform → physics → WLTP ratio), P10–P90 band; launch gate = back-test median error <10% on top-40 used. Weights in editable usage_profiles table. ABRP stays the trip planner (deep link); differentiator = whole catalogue, multiple weighted trips, winter by default. Quick check without map = Core 1; routed trips = Core 2; 1,000 km winter time score, towing/roof box = Next.
- 2026-11-15 — Open data release ships at launch (CC BY 4.0 bundle per release, gate-passed sources only) and is the launch hook (Menno; repo Decision 016).
- 2026-11-15 — Variant finder (repo Decision 019, docs/spec/variant-finder.md; spec tab added): one card per variant stays, plus a "differences only" toggle on generation pages and Compare and a variant change timeline (Core, computed); a "spot it in an ad" clue box per variant (year range, kW on papers, trim name per market, visible features, "ask the seller" lines; Core for the top 40, Next for the rest); "which one is it?" finder and NL plate lookup via RDW (Next; lookup runs in the visitor's browser only, repo Decision 036); listing-link paste only via partners (Later). Clues are one config-typed data table (Variant clue + Look-alike group) that also feeds listing matching (Menno).
- 2026-11-15 — Outreach in Menno's name waits until the brand name is chosen (Menno). Drafts ready in repo docs/outreach/drafts/ (incl. NL/DE/FR versions).

## Data
- 2026-11-14 — Open data first: no paid or licensed datasets. Sales/registrations from official sources; aggregators as fallback.
- 2026-11-15 — Every data point has 1–2 primary sources plus all available fallbacks (spec tab "Source matrix"). Code mirrors it in data/sources.yaml and data/field_sources.yaml (tolerance + merge rule per field); coverage report per release; target 80% of top-40 used models with ≥2 agreeing sources on headline fields; conflicts go to review; licence gate before public release.
- 2026-11-15 — Data model adds Platform and BatteryPack entities (pack facts inherited by variants) and taxonomy tables voltage_classes, chemistries, cooling_types, glossary_terms, so new architectures (900 V, 1,000 V) and chemistries (sodium-ion, semi-solid, solid-state, LMR) are a new row, not new code. "Not disclosed" is a real value; inferred values are low confidence.
- 2026-11-15 — Charging sources: Fastned curves (ask permission), Open EV Data (MIT + attribution, drop default curves), NAF El Prix, ADAC, P3 Charging Index, Automobile Propre, Bjørn Nyland. EVKX = manual cross-check only (terms forbid competing databases).
- 2026-11-15 — Added: RDW inspections + defects (CC0) and DVSA MOT history API (OGL) for a data-driven "Known issues" block; Aviloo battery report and Belgium Car-Pass battery test; emerging-market registration data (VAHAN, Thailand DLT, INEGI RAIAVL, ABVE, NZ MoT).
- 2026-11-15 — Charging infrastructure data: aggregates only, never point-level charger data (Open Charge Map's per-location CC BY-SA licences clash with our CC BY output). One official primary per country (RVO, Bundesnetzagentur, Avere-France, DfT, AFDC, EV Council), EAFO for all cross-country comparison, IEA Global EV Data Explorer (CC BY 4.0) as global fallback; Paren, Zapmap, T&E, BDEW cited with links, not ingested. New tables charging_stats + taxonomies charging_metrics, charging_definitions, power_bands; country_charging_links config; variant field abrp_typecode. One definition per series; definition changes = marked break. Licences checked (R-26): BNetzA CC BY 4.0, DfT OGL v3, NDW CC0, AFDC free; EAFO blocked until confirmed in writing (repo Decision 036).
- 2026-11-15 — Bidirectional data: taxonomies bidi_modes/routes/protocols/caveats/status, connector_types, bidi_equipment; entities BidiCapability (per variant/platform, per-country status + conditions) and ChargingPort (per market + model year); iso15118_20_support defaults to not disclosed, never inferred. Maker eligibility pages primary; The Mobility House list + energy companies as fallback. Facts older than 90 days show "may be out of date".
- 2026-11-15 — Trip fit data: taxonomies road_classes, speed_profiles (per country), temperature_bands, heater_types, usage_profiles; variant fields heat_pump (standard/option/none/not disclosed), drag_coefficient, frontal_area, kerb_mass, wheel_size, usable_kwh; condition-tagged consumption_tests; derived consumption_model per variant (rung + confidence); climate: ERA5-Land (CC BY 4.0) primary, Meteostat (CC BY 4.0) second; town search from GeoNames (CC BY 4.0) (repo Decision 036).
- 2026-11-15 — Finance rates: ECB MIR consumer-credit APRC for euro countries, Bank of England for the UK; NL blank until an official series exists (repo Decision 036, research R-20).
- 2026-11-14 — Published open data licence: CC BY 4.0. ODbL inputs kept separate (e.g. Washington DOL: internal only). Paid granular API later.

## Architecture
- 2026-11-14 — Lean monolith + data pipeline: Next.js + Postgres + Python jobs, open-source stack, staff area in-app. Solo builder with AI coding agents.
- 2026-11-15 — Hosting: on Menno's shared AppInfra server (Hetzner CAX31, Arm, 8 cores, 16 GB, next to GardenLayer and Dungeon Tracker). Reuse Caddy, CI→Arm image→SSH deploy, backups, watchdog (/health), Umami, Scaleway email, Sveltia editor, staging. Dropped Coolify, Brevo and Dagster (pg-boss + scheduled Python jobs instead). Raw snapshots in Scaleway Object Storage. Spec section 13.
- 2026-11-15 — Database: own database + login + private network inside the shared Postgres 17 + PostGIS server (AppInfra advice, reconfirmed by capacity check), not a separate container. Pool ~10 live / 3 staging / 3 jobs of 100 connections.
- 2026-11-15 — Limits: ev-web 768 MB / 1 CPU, ev-web-staging 256 MB / 0.5 CPU, ev-jobs 1 GB / 1 CPU at low priority, nightly only (00:30–02:30 UTC). Server total ~13.8 GB by day, ~14.8 GB in the job window (~1 GB over the README's 13.75 GB worst-case budget); fits while the paused Cahier app stays off. Upgrade to CAX41 or move GardenLayer out when busy evenings show >10 GB real use or >70% CPU for weeks.
- 2026-11-15 — AppInfra capacity check (quiet, Sat 23:31 UTC): 1.8 GB used of 15 GB, load 0.23, disk 11% (15/150 GB), backups ~3.8 GB over 14 days. Night window 00:30–02:30 UTC is clear of other server jobs (image refresh 03:00 1st Sun, backups ~10:30, Hetzner snapshot ~14:53). Umami at 73% of its 512 MB. No "add an app" checklist exists; steps spread over README sections 6, Caddy, Memory/CPU budget (7 touch points: compose service, caddy site, DB script, deploy-key scope, watchdog /health, backup.sh entry, Umami site).
- 2026-11-15 — Routing for Trip fit: self-hosted Valhalla (OSM) on a separate small Hetzner Arm box (~€5–15/month, sizing test first), not the shared CAX31. Hosted free routing APIs (openrouteservice, GraphHopper) are non-commercial → prototype/staging only. No Nominatim. Scoring runs in the browser: server returns a route summary per trip, browser multiplies it with a static per-variant consumption matrix. Addresses never stored server-side; coordinates rounded ~200 m; no logging on the route endpoint.
- 2026-11-15 — Public GitHub repo (free Actions minutes); code under AGPL-3.0, published data under CC BY 4.0; contributors agree to a relicensing clause. Repo Decision 002.
- 2026-11-15 — Sampling targets/rates and partner/affiliate secrets never in the public repo; runtime config only. Repo Decision 004.
- 2026-11-15 — Build arm64 images in GitHub Actions and run them on the existing Hetzner Arm server. Repo Decision 005.
- 2026-11-15 — Repo Decisions 012 (charging stats as aggregates, one definition per series), 013 (Trip fit: Valhalla box, browser scoring), 015 (/{country}/{lang}/ URLs + hreflang), 020–034 (overnight 1: schema conventions, refresh CLI, data-quality guards), 035 (published releases move out of git; temporary 25 MB cap), 036 (source choices from the research pack).
