How it works: `src/proxy.ts` (Next 16's renamed middleware) resolves the language per request: `?lang=` → cookie `lang` → country default (nl→nl, de→de, fr→fr, be→nl, uk→en). It passes the result on as the `x-ev-lang` header, so layouts (which can't see searchParams) and `<html lang>` use it. `t()` is a tiny helper with `{var}` interpolation; no library. Locales: en-GB, nl-NL, de-DE, fr-FR, es-ES, it-IT. Units are always metric. EN is complete; NL covers all strings shipped tonight. Taxonomy and glossary text comes per language from the data with EN fallback (`lib/taxonomy.ts` `loc()`).
