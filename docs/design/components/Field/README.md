# Field

Text inputs, selects and range sliders for search and filters.

- The label sits above the field (`evs-label`). A hint goes underneath in `ink-3`. Never placeholder-only.
- 48px tall, 17px text, a 1.5px `line-strong` border (3:1+), `radius-sm`, a focus outline in `focus`.
- Sliders always show their value as text in the label, and filters offer a typed alternative.
- Errors show after blur or submit: `danger` border plus an icon, what happened and what to do.
- Placeholders are real examples ("Utrecht"), not instructions.
