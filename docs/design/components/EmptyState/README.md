# EmptyState

What people see when a list, search or comparison has nothing in it: an illustration, one sentence, one action.

- A small doodle (180px wide) in the map palette: ink linework, one sky or sunflower fill. Empty states are one of the few places where hand-drawn style is welcome.
- Headline names the space ("Your shortlist is empty"), one sentence explains how to fill it, and one primary button acts.
- No-results searches name the filter that blocks the most cars and offer to clear it: "No cars under €8,000 with 300 km range. Clear the range filter."
- Never apologise, never "Oops".
