# SourceList

Nerd mode's source table under any figure: each source with its value, conditions, date and confidence.

- One row per source: value (bold), who measured it, confidence dots, then date and conditions in `caption`.
- The summary line on top says how the shown value was chosen ("3 sources agree within 5%. Shown: median.").
- Confidence is three dots with an aria-label ("Confidence high"), never colour alone.
- Conflicts get a caution chip and a "Report a data issue" ghost button.
- In Simple and Detailed modes this collapses to one caption line: "Source: NAF El Prix, Feb 2024 (+2 more)".
