# Textures

Standalone SVG tiles of the holiday-map textures, for designers and the Design board. In the product, use the `evs-tex` classes in `components/bundle.css` (they theme automatically); see the Texture component for rules.

| File | Use |
|---|---|
| paper-grain.svg | Faint paper grain for hero bands, empty states, share images |
| contour-lines.svg | Topographic lines for land and hero backgrounds (240×160 tile) |
| map-grid.svg | Dashed map grid with crosshair marks for Learn headers (48px tile) |
| land-hatch.svg | Diagonal hatching for land in illustrations (14px tile) |
| halftone-sun.svg | Sunflower halftone dots for sun shapes (10px tile) |
