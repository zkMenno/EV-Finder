# Illustrations

The solarpunk illustration kit (B + C style: layered paper hills, winding road, 2px ink line). Every file comes in `-day` (Day trip) and `-night` (Night drive). See the README section "Illustrations: solarpunk, within reach" for where each one goes.

| File | Use |
|---|---|
| scene-village-hero-day / scene-city-hero-day | Home hero only (rich colours) |
| scene-village-day / scene-city-day | Pages, empty states, /learn headers, share images (soft colours) |
| scene-village-night / scene-city-night | Dark theme versions of both |
| house-solar, house-solar-rich, row-houses, apartments, apartments-rich | Homes; every roof has solar |
| wallbox, public-charger, lamp-post-charger | Home, fast and kerbside charging |
| turbine, solar-field, sky | Energy and weather (sky = sun by day, moon and stars by night) |
| trees, trees-rich, street-tree | Greenery |
| ev, ev-van, bus, bike | Getting around (the night EV has its headlights on) |
| road-bend, road-straight, road-winding | Road pieces for dividers and empty states |

Generated by `workstreams/UX/tools/kit.py`, `city.py` and `export.py` in the repo. Decorative: use `alt=""` unless the picture carries meaning.
