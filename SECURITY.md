# Security

## Reporting a vulnerability

Please **don't** open a public issue. Report it privately through GitHub: **Security → Report a vulnerability** on this repo, or go straight to https://github.com/zkMenno/EV-Finder/security/advisories/new.

Include what you found, how to reproduce it and what impact you think it has. You'll get a reply within 7 days. This is a one-person project, so fixes may take longer, but serious issues come first.

## Scope

The code in this repo and the live site once it launches. Please don't test against other people's accounts, run load tests against production, or touch third-party marketplaces we link to.
