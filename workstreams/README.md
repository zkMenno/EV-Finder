# Workstreams

One folder per long-running chat: `START.md` (start prompt), `STATUS.md`, `INBOX.md` (append-only), `HANDOFF.md`.

How workstreams work, the workstream table, file ownership and the message-bus rules: **[docs/process/README.md](../docs/process/README.md)**. Direct links to every chat: [CHATS.md](../CHATS.md).

`OVERNIGHT/` and `OVERNIGHT2/` are finished one-off runs (archive, read-only).
