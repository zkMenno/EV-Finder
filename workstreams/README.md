# Workstreams

Lane briefs (`<lane>/START.md`: what the lane owns, its rules, verify steps, gotchas, done criteria) for WS1–WS5, UX and QA, plus the coordinator's files: `WS0/INBOX.md` (the one inbox, append-only for everyone) and `WS0/HANDOFF.md`. State lives in task files and PRs; batch chats read the brief of each lane they touch.

How chats, lanes, ownership and the message bus work: **[docs/process/README.md](../docs/process/README.md)**. Direct links to every chat: [CHATS.md](../CHATS.md).

Finished runs and the retired per-lane STATUS, INBOX and HANDOFF files are in `_archive/`, which chats never read.
